# my-first-pr

A practice repository for learning the GitHub pull request workflow.

## The workflow

1. Create a branch: `git checkout -b my-change`
2. Make a small change and commit it: `git commit -am "Describe the change"`
3. Push the branch: `git push -u origin my-change`
4. Open a pull request: `gh pr create`
5. Review, then merge it on GitHub.
